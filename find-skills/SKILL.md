# Find existing skills

Before building or planning something new, check whether a skill already covers
it. Search these sources for the task keywords:

- https://skillsmp.com/search
- https://mcpmarket.com/tools/skills
- https://claudeskills.info/
- https://github.com/BehiSecc/awesome-claude-skills
- https://github.com/travisvn/awesome-claude-skills
- https://github.com/VoltAgent/awesome-agent-skills

Use the `Explore` agent (or WebFetch / WebSearch) to query these for the task
keywords. If a relevant skill exists, prefer installing or using it over
building from scratch. Report any matches back with install or usage notes.
